HOW TO ADD MORE TIKTOK CLIPS
1. Open tiktok-clips.txt in Notepad or edit on GitHub.
2. Paste one full, public TikTok video URL per line; optionally: Title | URL.
3. Save and commit the updated file in the same GitHub repo as index.html.
4. Refresh Neva. New public links appear in Clips and are shuffled in.
5. No reupload, copyright copying or extra Supabase storage needed.

IMPORTANT: This does NOT include 1,000 TikTok posts yet. The file contains 22 sourced links;
add more valid links over time, up to 1,000. TikTok does not let any public website
simply mirror its whole feed. TikTok can also disable individual embeds.

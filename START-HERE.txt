NEVA CLASSIC DOCK + NOTIFICATION BAR + HD BUBBLES

This is a VISUAL UPDATE only. It keeps your existing video uploads, music,
profiles, Supabase settings, login system, themes and page contents.

IMPORTANT: Do not replace your current index.html with an older one.

INSTALL ON YOUR EXISTING GITHUB PAGES SITE

1. Open your existing Neva repository on GitHub.
2. Add the file neva-ui-update.js to the SAME place as index.html.
   To add it: Add file > Upload files > select neva-ui-update.js > Commit changes.
3. Click index.html on GitHub, then the pencil icon to edit it.
4. Scroll near the bottom of index.html, find </body>, and insert this line
   on its own line JUST ABOVE </body>:

   <script src="./neva-ui-update.js?v=1" defer></script>

5. Click Commit changes.
6. Open your existing Neva GitHub Pages address and refresh.

TEST FIRST: The dark glossy notification bar should appear near the top,
the compact glass dock should be at the bottom, and bubble symbols should
remain sharp even when enlarged.

ABOUT NOTIFICATIONS: The new top bar opens a notification panel and links to
Friends & Chat. It does not pretend to be a live notification service. Live
friend-message alerts would require additional backend work.

ABOUT THE ORIGINAL DOCK: This file restores the old compact Neva glass-dock
appearance. It keeps your site's existing dock buttons and navigation.

IF YOU NEED TO UNDO IT:
Remove the <script src="./neva-ui-update.js?v=1" defer></script> line from
index.html and commit. Nothing in Supabase has been changed.

SECURITY: This update doesn't need your Supabase key or any password.

NEVA IN YOUR POCKET

Install Neva

Get the bubble home screen on your phone. No app store needed.

Android: Open Neva in Chrome, tap the menu ⋮, then Install app or Add to Home screen.

iPhone: Open Neva in Safari, tap Share (the square and arrow), choose Add to Home Screen, then Add. Turn on Open as Web App if shown.

You must open the live website, not an HTML file from Downloads. Watching and uploading videos still needs internet.
